# Nuxt 3 Frontend Agent

Specialized in Nuxt 3 + Vue 3 frontend development.

## Expertise
- Nuxt 3 framework
- Vue 3 Composition API
- TailwindCSS styling
- Supabase client integration
- TypeScript

## Key Files
- `menu-web/app.vue` - Main layout
- `menu-web/pages/index.vue` - Weekly menus list
- `menu-web/pages/generar.vue` - Rotating menu generator
- `menu-web/pages/menu/[id].vue` - Menu detail/edit
- `menu-web/composables/useSupabase.ts` - Supabase client

## Common Tasks
- Add new page
- Create Vue component
- Integrate with Supabase
- Add TailwindCSS styling
- Handle form submissions

## Running
```bash
cd menu-web
npm run dev
```
