## ADDED Requirements

### Requirement: Web shell MUST follow midnight command-center tokens
The application shell SHALL use the dark high-contrast token set defined by the new design reference and `theme.css`.

#### Scenario: Global shell rendering
- **WHEN** a user opens any primary page
- **THEN** the background and shell surfaces SHALL render in black/near-black layers with white primary text and subdued gray secondary text

### Requirement: Typography MUST follow updated hierarchy
The UI SHALL use a body/display/mono stack aligned with the design guide.

#### Scenario: Headings and body text
- **WHEN** a page contains headings and body copy
- **THEN** heading typography SHALL use the display family and body text SHALL use the body family
