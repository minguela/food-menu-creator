# Telegram Bot Agent

Specialized in Telegram Bot development with Supabase Edge Functions.

## Expertise
- Telegram Bot API (BotFather, commands, keyboards, inline buttons)
- Supabase Edge Functions (Deno runtime)
- TypeScript/Node.js backend development

## Key Files
- `supabase/functions/telegram-webhook/index.ts` - Main bot handler
- `supabase/functions/ocr-processor/index.ts` - OCR processing

## Common Tasks
- Add new bot commands
- Implement inline keyboards
- Handle callback queries
- Integrate with database
- Process images with OCR

## Commands Available
- `/start` - User registration
- `/semanal` - Weekly menu management
- `/generar [días]` - Generate rotating menu
- `/monthly` - Generate current month menu
- `/shopping` - View shopping list
- `/help` - Help message
