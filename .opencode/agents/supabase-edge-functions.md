# Supabase Edge Functions Agent

Specialized in Supabase Edge Functions development.

## Expertise
- Deno runtime
- TypeScript
- Supabase database integration
- PostgreSQL queries

## Functions
- `telegram-webhook/` - Telegram bot webhook handler
- `ocr-processor/` - Google Cloud Vision OCR processing
- `generate-monthly-menu/` - Monthly menu generation and shopping list

## Key Files
- `supabase/functions/<function-name>/index.ts`
- `supabase/schema.sql`
- `supabase/migrations/*.sql`

## Common Tasks
- Create new edge function
- Add database query
- Integrate with external APIs (Google Cloud, Telegram)
- Handle authentication with service role key
